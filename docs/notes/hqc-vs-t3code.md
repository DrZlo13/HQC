# hqc против T3 Code: что там есть, а у нас нет

T3 Code (https://t3.codes, https://github.com/pingdotgg/t3code, MIT) — открытая оболочка для
Claude Code, Codex, Antigravity, OpenCode, Cursor и Grok: настольное приложение на Electron,
веб-клиент и нативные приложения для iOS и Android. Здесь — все его функции, которые видит
пользователь, и для каждой — есть ли она в hqc.

Устроены продукты по-разному. В T3 на каждой машине работает свой сервер, а клиент подключается к
каждой машине отдельно. В hqc один хаб, и воркеры сами подключаются к нему. Поэтому функции T3 про
доступ к машинам (QR-пары, маршруты, Tailscale) в hqc не нужны. Ещё одно отличие: SPEC hqc прямо
говорит «it is not an IDE: no file editor, diffs only as artifacts» (`docs/SPEC.md:39`). Под это
ограничение попадают git-панель, терминал, просмотр файлов и браузер T3.

  короткие вида `composer.md:15` — это `docs/user/composer.md`.
- Чем читался T3: пользовательская документация `docs/user/` (из 49 файлов 30 прочитаны целиком,
  7 — по заголовкам и началу: secrets, background-service, managed-policy, updating, install, cursor,

  https://t3.codes/download. Код — выборочно: компоненты и маршруты клиента, сочетания клавиш по
  умолчанию, настройки, инструменты MCP для агентов, голосовой ввод. Поведение функций описано по

Чего в hqc нет совсем и что ценнее всего, когда много сессий на нескольких машинах, с браузера и
телефона:

1. **Голосовой ввод.** На телефоне — главный способ быстро ответить сессии. Как сделано в T3 —
   ниже, «Как T3 делает голосовой ввод».
2. **Продолжение после сброса лимита и «отложить до сброса».** Сейчас сессия, упёршаяся в лимит,
   стоит, пока до неё не дойдут руки. Время сброса hqc уже знает (`worker.limits`).
3. **Заполнение контекстного окна.** С телефона не видно, что длинная сессия близка к сжатию.
4. **Side chat (`/side`, `/btw`).** Спросить работающую сессию «что ты делаешь», не сбив её ход.
5. **Откат к сообщению вместе с файлами.** «Fork from here» оставляет файлы как есть.
6. **Отложить сессию до времени (snooze).**
7. **Терминал на машине воркера из браузера.** Против «not an IDE» в SPEC.
8. **Запуск по webhook** (упал CI, пришёл PR). Сейчас есть только расписания.
9. **Live Activity и виджеты** — ход агента на экране блокировки. Из PWA не сделать, нужен
   нативный клиент.
10. **Уровень рассуждений (effort) в выборе модели.**

Из сделанного наполовину больше всего просятся доделать очередь ввода (правка, удаление, выбор
«влить в ход или ждать») и сводный дифф хода (против «not an IDE»).

Только в hqc, у T3 этого нет: живое зеркало и перехват сессий VS Code, сообщения и вопросы между
сессиями, общий список запросов «Requests», правила по папкам, перенос сессии в другой проект или
папку, полоса скорости токенов на панели проектов, поиск выделенного текста в вебе, Web Push без
открытого клиента.

## Как T3 делает голосовой ввод

- **Браузер и десктоп.** Браузер пишет звук с микрофона (`AudioWorkletNode`,
  `apps/web/src/speech/browserPcmCapture.ts:91`) и отправляет его на машину, выбранную в
  Settings → Voice; пока машина не выбрана, звук никуда не уходит (`voice-input.md:15-25`). Сервер
  этой машины распознаёт речь локально: `transcribe-cpp` 0.4.1 в отдельном процессе
  (`apps/server/package.json:75`; `docs/internals/voice-input.md:56-68`), тишину отсекает детектор
  Silero (`apps/server/src/speech/silero.ts:3`). Модели — из каталога
  `apps/server/src/speech/catalog.json`: 59 моделей GGUF, у 21 в списке языков есть русский; среди
  них GigaAM v3, Whisper Large v3 Turbo, Parakeet TDT v3, Qwen3-ASR. Вместо локальной модели запись
  можно отправить в облако: OpenAI `gpt-transcribe`, xAI `grok-voice-transcribe-2.0`
  (`apps/server/src/speech/CloudSpeech.ts:31-32`) или OpenRouter; ключ хранится на машине.
- **Что видит пользователь.** Кнопка микрофона или `mod+shift+d`, запись до 5 минут. Текст
  встаёт в черновик на место курсора и сам ничего не отправляет. Есть словарь терминов (личный и
  проектный), удаление слов-паразитов и по желанию «чистка» расшифровки текстовой моделью, по
  умолчанию выключенная (`voice-input.md:79-143`). Диктовать можно и в комментарии к диффу, к PR, в
  ответы на вопросы.
- **Телефон.** По умолчанию распознаёт само устройство: iOS 26+ — `@react-native-ai/apple`
  (`apps/mobile/package.json:70`, `apps/mobile/src/native/voiceTranscription.ios.ts:2`), Android
  12+ — ML Kit GenAI Speech Recognition
  (`apps/mobile/modules/t3-voice-transcription/android/build.gradle:21`). По желанию — на свою
  машину (`composer.md:205-244`).
- **hqc.** Заголовков, запрещающих микрофон, у хаба нет: `Permissions-Policy|microphone` по
  `crates/hqc-hub/src` и SPEC — ноль совпадений. Единственное упоминание голоса — флаг
  `voiceEnabled:false`, которым воркер выключает голос самого Claude Code
  (`crates/hqc-worker/src/title.rs:50-52`).
